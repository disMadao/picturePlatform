# 智能助手：视频生成方案（实现说明）

本文在原计划基础上补充**易遗漏点**与**运维约定**，并与仓库实现保持一致。

## 1. 架构摘要

- **火山方舟**：Python Agent 使用 `volcengine-python-sdk[ark]`，环境变量 `ARK_API_KEY`；模型 ID 等与 `[doubao_sendance_test.py](../agent-backend/agent_backend/test/doubao_sendance_test.py)` 对齐，可通过 `ARK_VIDEO_MODEL` 覆盖。
- **持久化**：临时视频 URL 由 **Java** 使用现有 `UrlVideoUpload` 拉取并写入 **COS**；元数据写入表 `**generated_video`**（**不**写入 `picture` 表）。
- **鉴权**：Agent 调用 Java 使用 `X-Internal-Token`；`/video/agent/persist` 在服务端**再次校验** Token，并校验 `**spaceId` 归属 `userId`**。

## 2. 数据库

- **建表**：`[picture-backend/sql/generated_video.sql](../picture-backend/sql/generated_video.sql)` 为 DDL 草稿；**由你在目标库执行**（本地无权限时代码不自动建表）。
- **索引**：建议 `(userId, spaceId)` 便于按空间列表查询；后续「空间内视频列表」可在此基础上加分页接口。

## 3. 遗漏与风险（检查清单）


| 项                | 说明                                                                                                        |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| **模式互斥**         | 前端仅允许 `session_intent` 为 `search` 或 `video`；后端对非法组合或视频模式缺 `space_id` 应返回明确业务错误码（如 `PARAMS_ERROR`），避免静默失败。 |
| **方舟可访问 URL**    | 首帧/尾帧图须为方舟可拉取的 **公网 HTTP(S)**；本地上传应先走 Java 图床上传拿到 URL。                                                    |
| **尾帧 API**       | 官方文档若与「第二条 `image_url`」不一致，以文档为准调整 `ark_video_client` 的 `content` 组装。                                     |
| **超时**           | 视频生成耗时长：Agent `/agent/chat` 与前端 axios 对视频模式使用更长超时（如 10 分钟）；第二迭代可改为异步任务 + 轮询。                              |
| **内部 Token 安全**  | `persist` 仅信任 header 与配置一致；生产限制 IP 或网络策略；勿将 Token 提交前端。                                                   |
| **COS 与 DB 一致性** | 若 COS 成功、DB 失败，可能产生**无记录对象**；可后续用定时任务清理或事务外补偿。                                                            |
| **会话与消息**        | `conversationId` 存于 `generated_video` 便于运营排查；与 `agent_message` 表无 FK 时需约定类型一致（bigint）。                    |
| **空间**           | 首期校验 **空间所有者** `space.userId == userId`；团队空间协作需另加 `SpaceUser` 权限。                                         |


## 4. 环境变量（Agent）


| 变量                     | 说明                              |
| ---------------------- | ------------------------------- |
| `ARK_API_KEY`          | 火山方舟 API Key                    |
| `ARK_VIDEO_MODEL`      | 可选，默认与测试脚本一致                    |
| `AGENT_INTERNAL_TOKEN` | 与 Java `agent.internalToken` 一致 |
| `JAVA_BASE_URL`        | 默认 `http://127.0.0.1:8123/api`  |


## 5. 相关代码入口

- Java：`VideoController` 增加 `/video/agent/persist`；`GeneratedVideo` 实体与 Service；`AgentInternalAuthFilter` 增加免 IP 校验路径后缀。
- Python：`agent_backend/ark_video_client.py`、`agent_backend/video_agent.py`；`main.py` 中 `/agent/chat` 按 `session_intent` 分支。
- 前端：`AgentPage.vue` 模式切换与 `spaceId`、帧 URL；`agentApi.ts` 请求体扩展。
